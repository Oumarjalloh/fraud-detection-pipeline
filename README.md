\# 🛡️ Real-Time Fraud Detection Pipeline



Pipeline de détection de fraude bancaire en temps réel basé sur une architecture Lambda.



\## 🎯 Objectif



Détecter les transactions bancaires frauduleuses en streaming, tout en permettant l'analyse historique et l'entraînement de modèles ML.



\## 🛠️ Stack technique



\- \*\*Python\*\* — Ingestion et orchestration

\- \*\*Apache Spark\*\* — Traitement batch et streaming

\- \*\*Apache Cassandra\*\* — Stockage des alertes temps réel (NoSQL, haute écriture)

\- \*\*PostgreSQL\*\* — Data mart pour l'analyse historique

\- \*\*Jupyter\*\* — Exploration de données et ML

\- \*\*Docker\*\* — Conteneurisation de l'ensemble
